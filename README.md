# RetroGame_Recommeder

A pixel-themed, retro-style interactive quiz that helps users discover the perfect classic game to play based on their preferences!

## Features

- 🎮 **Interactive Quiz** - Answer 5 questions about your gaming preferences
- 🎨 **Pixel-Perfect Design** - Authentic retro aesthetic with CRT scanlines and pixel fonts
- 🌟 **Smart Recommendations** - Intelligent matching algorithm finds your ideal game
- 💡 **Detailed Feedback** - Learn why each game was recommended for you
- ✨ **Animated UI** - Retro effects including twinkling stars and glowing elements

## How to Use

1. Open `index.html` in your web browser
2. Click "START QUIZ" to begin
3. Answer 5 questions about your preferences
4. Get your personalized retro game recommendation!

## Game Database

The quiz features 12 classic retro games from the golden age of gaming, including:
- Super Mario Bros.
- The Legend of Zelda
- Pac-Man
- Tetris
- Street Fighter II
- And more!

## Files

- `index.html` - Main quiz interface with pixel-themed styling
- `games.json` - Game database and quiz questions

## Technologies

- HTML5
- CSS3 (with retro pixel styling)
- Vanilla JavaScript
- Press Start 2P font (pixel font)
